# Text-to-Speech Summarizer 🎙️📄

A voice-enabled web application that **summarizes text using a T5 transformer model** and converts the generated summary into **speech output**.

This project combines **Natural Language Processing** and **speech technologies** to create an interactive and accessible summarization tool.

---

## 🚀 Features
- Text summarization using **T5 Transformer**
- Voice-based input using **SpeechRecognition**
- Audio output using **Google Text-to-Speech (gTTS)**
- Simple and interactive **Flask web interface**

---

## 🛠️ Tech Stack
- **Python**
- **Flask**
- **Hugging Face Transformers (T5)**
- **SpeechRecognition**
- **gTTS**

---

## 📌 Use Cases
- Quick understanding of long articles
- Accessibility support for visually impaired users
- Hands-free text summarization

---

Actively developed and improved as part of hands-on learning in NLP and AI.
